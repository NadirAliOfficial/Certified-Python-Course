## Description
This repository contains the course materials and example code for a school management system built with Python's Tkinter library. The GUI allows adding, viewing, updating, and deleting student records, which are stored in a CSV file.

## Features
- Graphical user interface for managing student data
- Add, view, update, and delete student entries
- Persistent storage using `students.csv`
- Simple input script (`py/nak.py`) demonstrating formatted output

## Installation
The project relies on the following Python packages:
```bash
pip install pandas
```
`tkinter` is included with the standard Python distribution.

## Usage
Run the main GUI application:
```bash
python py/data.py
```
Or execute the checkpoint script directly:
```bash
python .ipynb_checkpoints/data-checkpoint.py
```
A simple example script is also provided:
```bash
python py/nak.py
```
